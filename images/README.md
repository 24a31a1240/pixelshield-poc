# Test Images Directory

Place your test photos here:

- **images/input/**: Put your 1-2 test face photos here (jpg, png)
- **images/input/reference/**: (Optional) Put a different photo of the same person here for the attack test

## Example Usage

```bash
# After placing test images:
cp my_face.jpg images/input/
cp my_face_other_angle.jpg images/input/reference/
```
